### SC-022A

**Retrieve scoped evidence with hybrid ranking and budgets**

Type: implementation. Dependencies: SC-014, SC-021. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Compatible encrypted indexes, request context budgets and selected knowledge-scope contracts are ready.

**Scope**

- Combine FTS/BM25 and exact cosine results with reciprocal rank fusion, deduplicate chunks and fit selected evidence into the request budget.
- Filter permitted knowledge scope and index generation before ranking, and invalidate stale/deleted scope through cache reads.

**Acceptance**

- Exact terminology and semantic matches both retrieve useful source-linked chunks on a fixed corpus.
- Deleted/out-of-scope versions cannot enter prompts through caches or fallback queries; every emitted chunk retains version/location metadata.

**Focused checks**

- Evaluate expected exact/semantic retrieval cases, duplicate chunks and budget boundaries against a deterministic corpus.
- Test scope exclusions, deletion/tombstone changes and stale-cache reads, including misleading-but-similar text.

**Stop boundary / excluded work**

- No evidence UI, model-citation parsing or broad retrieval benchmark framework.

Owned areas: `src/Sidecue.Application/Retrieval/`, `src/Sidecue.Infrastructure/Retrieval/`, `tests/evals/retrieval/`.

Parent coverage: scope 1, 2; acceptance 1, 2; validation 1.

### SC-022B

**Validate citations and expose traceable evidence**

Type: implementation. Dependencies: SC-014, SC-021, SC-022A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Scoped hybrid retrieval and answer/evidence contracts are implemented; use fixed synthetic generated-answer fixtures.

**Scope**

- Validate returned citation IDs against the exact evidence supplied to a request and display source/version/location through the evidence UI.
- Separate syntactically valid citation identity from whether cited text actually supports the generated claim.

**Acceptance**

- Invented or stale citation IDs are rejected or clearly marked, and missing support is visible.
- Evidence navigation preserves selected scope and source provenance; a valid ID cannot itself certify the truth of a claim.

**Focused checks**

- Test fabricated IDs, deleted versions, omitted sources and source-navigation failures.
- Evaluate claim support using fixed misleading/supporting excerpts, and inspect the UI's unsupported-evidence presentation with synthetic answers.

**Stop boundary / excluded work**

- No new semantic-search algorithm, automatic fact invention or unrelated note editor.

Owned areas: `src/Sidecue.Application/Retrieval/`, `src/Sidecue.Desktop/Views/Evidence/`, `tests/evals/retrieval/`.

Parent coverage: scope 3; acceptance 2, 3; validation 1, 2.
