# SC-013: Validate a two-hour transcription session

[Parent acceptance](../IMPLEMENTATION_PLAN.md#sc-013) remains unchanged. Status, ownership and dependencies live only in [backlog.json](../../tasks/backlog.json).

Complete one leaf per prompt, including its focused checks and handoff. Check upstream dependencies, gates and the listed external prerequisites before claiming it. Stop after that leaf; do not automatically start its sibling. A completed child does not complete the parent.

Coverage numbers below refer to the parent backlog arrays, counting from 1. They distribute the work; they do not substitute for evidence. Update this card and the backlog together when scope changes.

### SC-013A

**Prepare the bounded transcription endurance run**

Type: implementation. Dependencies: SC-011, SC-012. Gates: G0. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Integrated transcription, dashboard and recovery are available; prepare synthetic speech and an explicit device/provider checklist.

**Scope**

- Prepare a repeatable two-hour scenario and metadata-only measurements for the existing integrated pipeline.
- Define timed USB/default-device, network, overlapping-speech, pause and end-timeout interventions with expected states, gaps and committed transcript outcomes.

**Acceptance**

- The run records stage latency samples, non-history memory, source/epoch labels and control responsiveness without logging transcript/prompt bodies or secrets.
- The procedure names hardware/provider prerequisites and an explicit two-hour stopping point; missing prerequisites prevent execution rather than a simulated passing report.

**Focused checks**

- Run a short deterministic fixture to check measurement units, p50/p95 calculation and injected-outage markers.
- Inspect a generated synthetic diagnostic sample for forbidden content; a rehearsal does not satisfy endurance acceptance.

**Stop boundary / excluded work**

- Do not execute the full two-hour run here or expand diagnostics into a telemetry service.

Owned areas: `tools/diagnostics.ps1`, `tests/Sidecue.Replay.Tests/`, `docs/evidence/SC-013A/`.

Parent coverage: scope 1, 2; acceptance 1, 2, 3; validation 1, 2.

### SC-013B

**Execute and assess the two-hour transcription run**

Type: verification. Dependencies: SC-011, SC-012, SC-013A. Gates: G0. Interactive Windows evidence: required.

**Prerequisites**

- An uninterrupted two-hour window, physical headset/playback devices, configured test speech provider and the prepared measurement procedure are available.

**Scope**

- Run the prepared two-hour scenario with real devices and synthetic or explicitly authorized speech, recording all planned interruptions.
- Inspect logs and results, and turn each discovered pipeline defect into a separately bounded corrective child with affected acceptance and rerun requirements.

**Acceptance**

- Evidence records OS/device/provider settings, measured p50/p95, memory trend, pause/hide responsiveness and an observed result for every outage.
- The completed run exposes any corruption, lost gap, attribution or privacy failure honestly. The parent cannot close until corrective children resolve findings and affected evidence passes.

**Focused checks**

- Exercise USB/default-device changes, network interruption, overlap, pause and end timeout during the run; compare committed transcript identities before and after recovery.
- Check diagnostics for secrets, prompts and transcript content; retain failed results and link corrective work instead of silently rerunning until green.

**Stop boundary / excluded work**

- No unlimited debugging session or unrelated optimization; this child records the run and disposition of findings, not a claim that all new defects are fixed.

Owned areas: `docs/evidence/SC-013B/`, `tasks/backlog.json`.

Parent coverage: scope 1, 2, 3; acceptance 1, 2, 3; validation 1, 2.
