### SC-024A

**Durably enqueue and recover post-meeting jobs**

Type: implementation. Dependencies: SC-012, SC-014, SC-015. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Session recovery, encrypted transactional persistence and background-job contracts are implemented.

**Scope**

- Atomically finalize the session and enqueue one uniquely keyed job referencing fixed transcript/profile versions.
- Implement bounded claiming, expiring leases, fencing and retry/failure states using the existing job-store contracts.

**Acceptance**

- A crash around finalize/enqueue/claim cannot lose the required job or create duplicate jobs for the same input.
- Only the current lease can commit completion; restart resumes eligible work while permanent errors remain actionable.

**Focused checks**

- Kill/restart the test process around enqueue and claim boundaries and inject transient/permanent generation failures through a fake worker.
- Assert immutable input references, unique job identity, lease fencing and bounded retry without generating real notes.

**Stop boundary / excluded work**

- No production notes prompts, evidence-quality evaluation or user-edit versioning yet.

Owned areas: `src/Sidecue.Infrastructure/Jobs/`, `src/Sidecue.Application/MeetingArtifacts/`, `tests/Sidecue.Infrastructure.Tests/Jobs/`.

Parent coverage: scope 1; acceptance 1; validation 1.

### SC-024B

**Generate grounded structured meeting drafts**

Type: implementation. Dependencies: SC-012, SC-014, SC-015, SC-024A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Durable jobs, versioned profiles, generation adapter and transcript-evidence contracts are ready.

**Scope**

- Generate summaries, decisions, open questions and action items from the job's fixed finalized transcript evidence and profile/template version.
- Retain transcript references and explicit incompleteness while treating transcripts/provider responses as untrusted content.

**Acceptance**

- Generated facts refer to supplied final evidence; provisional tails cannot become established decisions.
- Unestablished owners and due dates remain unassigned, and unsupported claims fail the evaluation rather than acquiring invented citations.

**Focused checks**

- Use fictional fixtures for disputed decisions, missing owners/dates, incomplete endings and adversarial transcript instructions.
- Evaluate claim support and citation validity using fixed response fixtures and the established generation adapter; inject generation failures through the job boundary.

**Stop boundary / excluded work**

- No note editing UI, automatic sending, broad model selection or speculative artifact types.

Owned areas: `src/Sidecue.Application/MeetingArtifacts/`, `prompts/meeting-notes/`, `tests/evals/notes/`.

Parent coverage: scope 2; acceptance 2, 3; validation 1, 2.

### SC-024C

**Commit draft versions without overwriting user edits**

Type: implementation. Dependencies: SC-012, SC-014, SC-015, SC-024B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-024A/B durable worker and grounded generation plus the existing encrypted store/migration mechanism; do not wait for the later SC-025 editor UI.

**Scope**

- Add artifact/edit-version persistence and migrations, then commit generated drafts using idempotency keys with separate generated/user-edited versions.
- Fence stale job completion and preserve edited notes across retries, regeneration and process restart.

**Acceptance**

- Repeated or resumed completion cannot duplicate an artifact or replace user edits; regeneration creates the intended separate version.
- Committed drafts retain their fixed evidence/profile provenance and incompleteness/owner/date semantics from generation.

**Focused checks**

- Kill/restart around artifact commit, replay completion, expire a lease and edit a draft before retry.
- Verify that idempotency and version selection preserve edits while generated claims/citations remain tied to supplied evidence.

**Stop boundary / excluded work**

- No searchable history/note editor UI or retention scheduler; those remain later tasks.

Owned areas: `src/Sidecue.Application/MeetingArtifacts/`, `src/Sidecue.Infrastructure/Jobs/`, `tests/Sidecue.Infrastructure.Tests/Jobs/`, `tests/evals/notes/`, `src/Sidecue.Infrastructure/Persistence/Migrations/`.

Parent coverage: scope 3; acceptance 1, 2, 3; validation 1, 2.
