### SC-015A

**Normalize OpenAI generation streams behind the application contract**

Type: implementation. Dependencies: SC-001, SC-014. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Typed generation/snapshot contracts and bounded immutable context are ready; verify current official OpenAI wire/SDK details before selecting an adapter dependency.

**Scope**

- Implement the initial OpenAI request/response adapter for text and declared image capability with provider-specific types confined to Infrastructure.
- Map synthetic stream frames into text, completion, failure and optional usage events while retaining request/session/context identity.

**Acceptance**

- Fake streams use the same application request/answer contracts as the real transport implementation.
- Absent usage stays unknown, unsupported image capability is rejected before sending, and raw reasoning or provider payloads are excluded from diagnostics.

**Focused checks**

- Test partial chunks, completion, malformed events, missing usage and stream failure using deterministic wire fixtures.
- Inspect logged metadata to ensure keys, prompt bodies and raw reasoning never appear.

**Stop boundary / excluded work**

- No live-provider calls, provider switching, request-priority coordinator or approved-image UI.

Owned areas: `src/Sidecue.Infrastructure/Generation/`, `tests/Sidecue.Infrastructure.Tests/Generation/`, `tests/fixtures/providers/`.

Parent coverage: scope 1, 2; acceptance 1, 3; validation 1.

### SC-015B

**Bound generation cancellation, retries and provider selection**

Type: implementation. Dependencies: SC-001, SC-014, SC-015A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Normalized stream adapter and synthetic transport fixtures are implemented.

**Scope**

- Complete transport cancellation, timeout, authentication and rate-limit classification with explicit bounded retry policy.
- Resolve configurable model IDs and capabilities through enabled-provider configuration; disallow silent vendor fallback.

**Acceptance**

- Cancellation disposes the stream promptly and cannot become a successful completion; timeout/authentication/limit failures remain typed and actionable.
- Retry attempts and delays are bounded and never resend to a provider the user has not enabled.

**Focused checks**

- Use fake transport and time to cover cancellation before send, mid-stream failure, timeouts, authentication denial and exhausted rate-limit retries.
- Verify request bodies and logs obey capability, provider allowlist and secret/content redaction rules.

**Stop boundary / excluded work**

- No automatic provider selection, live-model evaluation or app-level request fencing implementation.

Owned areas: `src/Sidecue.Infrastructure/Generation/`, `tests/Sidecue.Infrastructure.Tests/Generation/`.

Parent coverage: scope 2, 3; acceptance 2, 3; validation 1.

### SC-015C

**Verify a configured generation provider with synthetic input**

Type: verification. Dependencies: SC-001, SC-014, SC-015B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Configured test credentials, explicit live-test mode, provider availability and a reviewed pinned model/configuration are present.

**Scope**

- Run a separately enabled smoke check through the production adapter using a small synthetic prompt and an explicitly configured model.
- Record exact provider/model/configuration, streaming outcome, cancellation result and available usage without storing secret payloads.

**Acceptance**

- The live request exercises the same application contract as the passing fake transport tests.
- Evidence distinguishes actual observed capability from declared support; unavailable credentials or disabled test mode keep this verification pending.

**Focused checks**

- Observe partial text and terminal state on one controlled request and exercise cancellation using the configured adapter.
- Inspect diagnostics for prompt/key/reasoning leakage and record missing usage explicitly.

**Stop boundary / excluded work**

- No broad model comparison, real meetings, automatic account provisioning or provider fallback.

Owned areas: `docs/evidence/SC-015C/`, `tests/Sidecue.Infrastructure.Tests/Generation/`.

Parent coverage: scope 1, 2, 3; acceptance 1, 2, 3; validation 2.
