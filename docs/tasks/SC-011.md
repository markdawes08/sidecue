### SC-011A

**Show source diagnostics and provider readiness**

Type: implementation. Dependencies: SC-007, SC-010. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-007/010 services available; Windows UI Automation environment and synthetic diagnostics fixtures.

**Scope**

- Add microphone/playback selection, audio meters and provider readiness through application services.
- Present no-device, denied-permission and unavailable-provider states without exposing secrets or starting capture implicitly.

**Acceptance**

- A user can identify and verify each intended source before starting; failed readiness stays visible.
- Diagnostics reflect real service state rather than success-shaped mock indicators.

**Focused checks**

- Use focused view-model and UI Automation cases for source validation, missing endpoints and denied permissions.

**Stop boundary / excluded work**

- No session controls, live transcript view, provider account wizard or settings redesign.

Owned areas: `src/Sidecue.Desktop/Views/Diagnostics/`, `src/Sidecue.Desktop/ViewModels/`, `tests/Sidecue.Ui.Tests/`.

Parent coverage: scope 1, 2; acceptance 1; validation 1, 2.

### SC-011B

**Add session controls and a responsive transcript view**

Type: implementation. Dependencies: SC-007, SC-010, SC-011A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-011A diagnostics; SC-007 lifecycle and SC-010 live/unsaved event stream; interactive UI test session.

**Scope**

- Connect start/pause/end to the application controller and show capture, degraded and unsaved states distinctly.
- Render partial/final transcript updates in a virtualized list without moving pipeline work onto the dispatcher.

**Acceptance**

- Controls display the actual lifecycle and saved/unsaved state; Pause does not stand in for Hide or End.
- A representative long replay keeps scrolling and control input responsive within recorded test conditions.

**Focused checks**

- UI Automation covers start/pause/end and degraded states; load a fixed long replay and measure dispatcher/control response.

**Stop boundary / excluded work**

- No overlay integration, note/history editor or release performance benchmark.

Owned areas: `src/Sidecue.Desktop/Views/Session/`, `src/Sidecue.Desktop/ViewModels/`, `tests/Sidecue.Ui.Tests/`.

Parent coverage: scope 1, 2; acceptance 1, 2; validation 1, 2.

### SC-011C

**Copy and export committed transcript evidence**

Type: implementation. Dependencies: SC-007, SC-010, SC-011B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-011B dashboard and committed snapshot access; synthetic transcript fixtures and writable/failing test destinations.

**Scope**

- Provide copy/export for committed transcript text with an explicit destination and safe failure reporting.
- Include known gaps and completeness markers; any retained provisional tail remains clearly labelled and separate from finalized text.

**Acceptance**

- Exported/copy content preserves source order and evidence status, without inventing final text for missing intervals.
- A failed destination write cannot be reported as success, and export does not mutate stored transcript.

**Focused checks**

- Run focused UI/integration checks for export selection, incomplete/gapped evidence, provisional tails and write failure.

**Stop boundary / excluded work**

- No sharing service, automatic sending, notes export or broad file-format support.

Owned areas: `src/Sidecue.Desktop/Views/Session/`, `src/Sidecue.Desktop/ViewModels/`, `tests/Sidecue.Ui.Tests/`.

Parent coverage: scope 3; acceptance 3; validation 1.
