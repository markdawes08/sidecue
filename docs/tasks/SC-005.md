### SC-005A

**Capture one selected target into an explicit preview**

Type: implementation. Dependencies: SC-000, SC-002. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-002 overlay boundary; interactive Windows for the system picker and selected-target API probe.

**Scope**

- Use Windows.Graphics.Capture and the system picker to acquire a single bounded in-memory screenshot lease.
- Add a prototype preview with explicit Include/Cancel; preview alone does not authorize upload.

**Acceptance**

- Target selection retains native identity, including same-resolution displays; cancellation yields no approved image.
- Capture and preview dispose rejected/replaced buffers and create no screenshot cache or file.

**Focused checks**

- Test picker cancellation, preview cancellation, explicit inclusion and lease disposal through synthetic capture boundaries; perform a local picker smoke check.

**Stop boundary / excluded work**

- No provider upload, automatic capture or request integration; those belong to SC-023.

Owned areas: `src/Sidecue.Windows/ScreenCapture/`, `src/Sidecue.Desktop/Prototypes/ScreenCapture/`, `tests/Sidecue.Windows.Tests/ScreenCapture/`.

Parent coverage: scope 1, 2; acceptance 1, 2; validation 2.

### SC-005B

**Handle screenshot target changes and resource failures**

Type: implementation. Dependencies: SC-000, SC-002, SC-005A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-005A selected-target capture and lease ownership; fake capture failures.

**Scope**

- Handle resize, target closure, cancellation races and device loss around the single-frame capture/preview lifecycle.
- Define explicit unsupported/HDR handling under the intended matrix without substituting another monitor.

**Acceptance**

- Lost/closed targets produce a visible failure or explicit reselection; no first-monitor fallback occurs.
- Every failure/cancel path releases frame pools and image leases; unsupported formats are reported rather than mislabeled.

**Focused checks**

- Use focused device-loss, resize, unsupported-format and cancellation fakes to check outcomes and disposal.

**Stop boundary / excluded work**

- No image generation, persistent media, broad graphics compatibility claim or provider vision wiring.

Owned areas: `src/Sidecue.Windows/ScreenCapture/`, `tests/Sidecue.Windows.Tests/ScreenCapture/`.

Parent coverage: scope 3; acceptance 1, 2, 3; validation 2.

### SC-005C

**Verify physical screenshot selection and cancellation**

Type: verification. Dependencies: SC-000, SC-002, SC-005B. Gates: none. Interactive Windows evidence: required.

**Prerequisites**

- SC-005A/B complete; interactive Windows, synthetic targets, multiple same-resolution displays and any HDR setup included in the claim.

**Scope**

- Run real picker/preview/include/cancel, resize and target-close scenarios across the declared display cases.
- Inspect app-created temporary/cache locations while using synthetic screen content.

**Acceptance**

- The selected target matches the preview, including same-resolution monitors; cancelling leaves no upload or screenshot file.
- Observed resize/HDR/unsupported behavior and resource cleanup are recorded with exact Windows/display configuration.

**Focused checks**

- Execute the relevant WIN screenshot cases and retain redacted results for picker cancellation, target identity, resizing and closure.

**Stop boundary / excluded work**
