### SC-033A

**Prepare bounded soak, fault and privacy measurements**

Type: implementation. Dependencies: SC-027, SC-028, SC-029, SC-030, SC-031, SC-032. Gates: G3. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Completed upstream integrated features and gates; declared workload, supported environment and measurable engineering targets.

**Scope**

- Prepare the overnight run procedure, synthetic workload and metadata-only diagnostics for queue/memory trends, control response and stage timing.
- Prepare the finite disk-full, network, long-transcript, concurrent deletion, cancellation and restart fault cases plus a privacy artifact inventory.

**Acceptance**

- Measurements distinguish durable history growth from transient memory and retain failed/timed-out samples.
- Diagnostics can measure p50/p95 without capturing raw audio, screenshots, keys, prompts or transcript bodies.

**Focused checks**

- Run a short deterministic fixture to verify metric aggregation, fault triggers and privacy-canary inspection; do not treat the short run as overnight acceptance.

**Stop boundary / excluded work**

- The real overnight run is SC-033B; full fault/privacy observations are SC-033C. No speculative benchmark framework.

Owned areas: `tools/diagnostics.ps1`, `tests/Sidecue.Replay.Tests/`, `tests/evals/`, `docs/evidence/SC-033A/`.

Parent coverage: scope 1, 2, 3; acceptance 1, 3; validation 1, 2.

### SC-033B

Type: verification. Dependencies: SC-027, SC-028, SC-029, SC-030, SC-031, SC-032, SC-033A. Gates: G3. Interactive Windows evidence: required.

**Prerequisites**

- SC-033A; an available overnight window, interactive supported Windows/device environment, synthetic or explicitly authorized speech and enabled test-provider credentials when used.

**Scope**

- Run the declared overnight synthetic/authorized meeting workload on the supported Windows environment.
- Record stage p50/p95, non-history memory trend, queue peaks, control responsiveness and all failures under the documented conditions.

**Acceptance**

- The completed duration has evidence for bounded transient memory and responsive controls; failed or interrupted runs remain recorded as such.
- Latency summaries include sample counts, failures and conditions, and do not become unsupported product guarantees.

**Focused checks**

- Execute the prepared overnight workload once, preserve metadata-only artifacts and compare measurements with the stated targets.
- Do not keep rerunning blindly; record anomalies for SC-033D to route into scoped corrective tasks and justified follow-up runs.

**Stop boundary / excluded work**

- No unrelated implementation changes, broad model tuning or indefinite soak extension in this run.

Owned areas: `docs/evidence/SC-033B/`.

Parent coverage: scope 1; acceptance 1; validation 1.

### SC-033C

**Execute targeted fault recovery and privacy inspections**

Type: verification. Dependencies: SC-027, SC-028, SC-029, SC-030, SC-031, SC-032, SC-033B. Gates: G3. Interactive Windows evidence: required.

**Prerequisites**

- SC-033A/B records; isolated disposable stores, controlled network/disk faults and synthetic privacy canaries on the supported Windows environment.

**Scope**

- Run the prepared disk-full, network, long transcript, deletion-during-work, cancellation and restart cases.
- Inspect app-managed logs, temp/cache files and configured crash behavior for raw media, credentials and unintended plaintext using synthetic canaries.

**Acceptance**

- Transcript/provider/storage faults remain visible and recover within documented limits, with incomplete or unsaved data identified.
- Automatic diagnostics and app-created raw-media files contain none of the prohibited synthetic content or secrets.

**Focused checks**

- Record the expected and actual outcome of each finite fault case and each relevant artifact category; keep negative and unavailable observations explicit.
- Route defects into scoped corrective tasks instead of expanding this verification block into general implementation.

**Stop boundary / excluded work**

- No real private meetings, full-memory dump uploads, exhaustive fuzzing or unrelated security certification.

Owned areas: `docs/evidence/SC-033C/`, `tests/Sidecue.Replay.Tests/`, `tests/evals/`.

Parent coverage: scope 2, 3; acceptance 2, 3; validation 2.
