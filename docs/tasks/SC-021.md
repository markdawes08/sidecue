### SC-021A

**Implement the configured embedding adapter**

Type: implementation. Dependencies: SC-020. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Versioned document chunks, embedding contracts and enabled-provider configuration boundaries are available.

**Scope**

- Implement the initial embedding provider adapter with bounded batches, cancellation, typed failures and explicit provider/model/dimension metadata.
- Send only selected imported chunk text to the enabled provider and make cloud-indexing disclosure match that payload.

**Acceptance**

- Unsupported dimensions or response cardinality fail before vectors are accepted.
- No silent provider fallback occurs, and document text/credentials remain absent from logs.

**Focused checks**

- Use synthetic transport fixtures to verify payload scope, response count/dimensions, cancellation and bounded retry.
- Check the disclosure against observed request fields; no live-provider benchmark is required for this adapter slice.

**Stop boundary / excluded work**

- No index storage schema, generation publication, retrieval or optional provider routing.

Owned areas: `src/Sidecue.Infrastructure/Embeddings/`, `tests/Sidecue.Infrastructure.Tests/Indexing/`.

### SC-021B

**Store encrypted versioned keyword and vector indexes**

Type: implementation. Dependencies: SC-020, SC-021A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Embedding metadata contracts, imported document versions and the validated SQLCipher distribution are available.

**Scope**

- Add encrypted FTS/vector storage keyed by document version and index generation.
- Record provider/model/dimension/normalization/chunking metadata and reject incompatible writes or search vectors.

**Acceptance**

- Index metadata makes a model/dimension change a distinct rebuild generation rather than a mixed vector set.
- FTS, vectors and temporary index artifacts remain within validated encrypted storage, with no plaintext side database or vector file.

**Focused checks**

- Test model/dimension/chunk-version mismatches, duplicate chunk writes and generation-scoped reads.
- Use synthetic canaries and the existing storage proof to check encrypted FTS/vector representations and journal handling.

**Stop boundary / excluded work**

- No restartable worker, active-generation switch or search ranking yet.

Owned areas: `src/Sidecue.Infrastructure/Retrieval/Indexing/`, `tests/Sidecue.Infrastructure.Tests/Indexing/`.

Parent coverage: scope 1, 3; acceptance 1, 2; validation 1, 2.

### SC-021C

**Publish complete indexes through restartable ingestion jobs**

Type: implementation. Dependencies: SC-020, SC-021B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Embedding adapter and encrypted generation storage are ready; use deterministic transport and failure injection for ordinary checks.

**Scope**

- Orchestrate bounded, restartable ingestion jobs over embedding and encrypted index storage.
- Publish a complete generation atomically after validation; retain the previous usable generation until the replacement is ready.

**Acceptance**

- Retry/restart and duplicate import cannot expose a half-built document version or publish an obsolete cancelled generation.
- Model/dimension changes schedule a separate rebuild, and actual outbound document text still matches the enabled-provider disclosure.

**Focused checks**

- Interrupt jobs before/after batch commit and publication, then test resume, cancellation and duplicate submissions.
- Verify atomic switches, generation compatibility and absence of plaintext indexing artifacts; repeat only affected adapter/storage checks.

**Stop boundary / excluded work**

- No retrieval algorithm, document editor or unrelated job framework; use the existing durable-job contract.

Owned areas: `src/Sidecue.Infrastructure/Retrieval/Indexing/`, `tests/Sidecue.Infrastructure.Tests/Indexing/`.

Parent coverage: scope 1, 2, 3; acceptance 1, 2, 3; validation 1, 2.
