### SC-020A

**Build the bounded import pipeline for text and Markdown**

Type: implementation. Dependencies: SC-004, SC-008. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- The upstream encrypted store and migration mechanism are available; this leaf owns document-specific storage/types. Establish explicit input and chunk limits.

**Scope**

- Implement shared import limits, cancellation, source hashing and versioned extraction/chunk metadata, starting with TXT and Markdown.
- Add document/version/chunk migrations and minimal typed provenance using the existing encrypted store. Persist extracted text with heading/range locations and preserve prior versions on failed replacement.

**Acceptance**

- Equivalent content has stable source identity and chunks reference their extraction/source versions.
- Malformed, empty and oversized inputs produce visible bounded outcomes without leaking document text to logs or plaintext indexes.

**Focused checks**

- Use synthetic Unicode/heading/empty/oversized fixtures and cancellation during extraction.
- Verify stored text/index representations remain encrypted and failed replacement leaves the earlier document version intact.

**Stop boundary / excluded work**

- No DOCX/PDF parsing, OCR, legacy DOC conversion, embeddings or retrieval implementation.

Owned areas: `src/Sidecue.Infrastructure/Documents/`, `tests/Sidecue.Infrastructure.Tests/Documents/`, `tests/fixtures/documents/`, `src/Sidecue.Infrastructure/Persistence/Migrations/`, `src/Sidecue.Core/Documents/`.

### SC-020B

**Add bounded DOCX extraction with source locations**

Type: implementation. Dependencies: SC-004, SC-008, SC-020A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- TXT/Markdown import pipeline works; select and record a reviewed parser dependency and its redistribution terms.

**Scope**

- Add DOCX extraction through the shared import pipeline, preserving headings, paragraphs and table locations in versioned chunks.
- Treat document contents and embedded objects as untrusted data; report unsupported legacy DOC without conversion or embedded-code execution.

**Acceptance**

- DOCX imports preserve stable source/version identity and traceable locations while respecting limits and cancellation.
- Malformed archives and oversized expanded content fail visibly without replacing prior document versions or creating plaintext side storage.

**Focused checks**

- Test synthetic headings/tables, Unicode, empty content, malformed archives, expansion limits and parse cancellation.
- Verify legacy DOC rejection, encrypted persistence and document-content redaction using the common pipeline.

**Stop boundary / excluded work**

- No Office automation, macros, embedded executables, legacy conversion or PDF support in this child.

Owned areas: `src/Sidecue.Infrastructure/Documents/`, `tests/Sidecue.Infrastructure.Tests/Documents/`, `tests/fixtures/documents/`.

### SC-020C

**Add text-PDF extraction and explicit scanned-document handling**

Type: implementation. Dependencies: SC-004, SC-008, SC-020B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- Shared import pipeline and DOCX support are stable; use a reviewed text-PDF parser with documented license and resource bounds.

**Scope**

- Add bounded text-PDF extraction preserving page/range provenance through the shared import pipeline.
- Identify unsupported scanned/image-only documents and fail or label them explicitly without pretending text was extracted.

**Acceptance**

- PDF chunks retain stable source/extraction identity and page references; malformed, oversized or cancelled imports preserve prior versions.

**Focused checks**

- Test synthetic multi-page text, Unicode, empty/scanned PDFs, malformed files, limits and cancellation.
- Verify page references and encrypted storage, and run the shared text/DOCX/PDF import cases once to detect format-integration regressions.

**Stop boundary / excluded work**
