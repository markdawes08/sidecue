### SC-010A

**Connect the bounded two-source transcript pipeline**

Type: implementation. Dependencies: SC-003, SC-007, SC-008, SC-009. Gates: G0. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-003/007/008/009 complete and G0 passed; bounded contracts and replay harness available.

**Scope**

- Compose capture/normalization/transcription with finalized persistence through the established interfaces.
- Expose partial/final transcript events, gaps and queue pressure to the session controller while preserving source/timeline/epoch metadata.

**Acceptance**

### SC-010B

**Stop acquisition on persistence failure**

Type: implementation. Dependencies: SC-003, SC-007, SC-008, SC-009, SC-010A. Gates: G0. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-010A composed pipeline and session lifecycle; injectable persistence failures.

**Scope**

- Route failed/ambiguous persistence outcomes into RecoveryRequired without depending on the failing store to report them.
- Bound retained unsaved text, stop new capture before it fills, and expose saved versus unsaved state explicitly.

**Acceptance**

- Disk-full/locked-store simulations stop acquisition and never report an uncommitted segment as saved.
- Already retained text is bounded and visibly unsaved; queue/gap reporting survives the failure path.

**Focused checks**

- Replay failed writes and slow consumers with a deterministic clock, including failure during stop and full unsaved-buffer pressure.

**Stop boundary / excluded work**

- No complete restart recovery, dashboard export or unrelated fault-injection matrix.

Owned areas: `src/Sidecue.Application/Capture/`, `src/Sidecue.Application/Transcripts/`, `tests/Sidecue.Application.Tests/Pipeline/`.

Parent coverage: scope 2, 3; acceptance 2, 3; validation 1.

**Focused checks**
