### SC-009A

**Normalize synthetic Deepgram protocol events**

Type: implementation. Dependencies: SC-001, SC-003B. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-001 normalized contracts; official protocol semantics reviewed when implementing; synthetic wire fixtures.
- Reuse the SC-003B Application timing helper with synthetic send outcomes; do not implement a second incompatible interval map.

**Scope**

- Implement provider-event parsing and stable segment/event identity behind IStreamingTranscriber without live transport.
- Map is_final versus speech_final, source-scoped speaker IDs and sent-sample intervals into normalized events and timing certainty.

**Acceptance**

- Partials, finalized segments and utterance boundaries remain distinct; repeated text alone never defines identity.

**Focused checks**

### SC-009B

**Implement bounded dual-stream speech transport**

Type: implementation. Dependencies: SC-001, SC-009A. Gates: none. Interactive Windows evidence: not required by this leaf.

**Prerequisites**

- SC-009A normalization; local fake transport and runtime configuration/credential boundary.

**Scope**

- Create independent microphone/remote WebSocket sessions with configured model, audio format and endpointing settings.
- Handle cancellation/drain, bounded queues/retries, authentication failures and reconnect epochs with safe diagnostics.

**Acceptance**

- Connection loss is visible and cannot trigger unbounded backlog or blind audio replay; unknown send completion preserves uncertainty.
- Invalid credentials fail actionably without endless retries or vendor switching; keys stay outside source/logs.

**Focused checks**

- Run local fake-WebSocket cases for close, timeout, authentication, malformed events and cancellation; verify independent sources and reconnect mappings.

**Stop boundary / excluded work**
