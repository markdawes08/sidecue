### SC-034B

**Verify the reviewable release artifacts and operating guide**

Type: verification. Dependencies: SC-033, SC-034A. Gates: G0, G1, G2, G3. Interactive Windows evidence: required.

**Prerequisites**

- SC-034A; approved signing capability, clean standard-user Windows environment, synthetic test data and complete preceding phase evidence.

**Scope**

- Build the release from clean source, compare its manifest/dependency/model configuration with tested artifacts, and inspect contents, signatures and notices.
- Exercise the documented install/use/recover/update path against the reviewed build in the declared clean Windows environment.

**Acceptance**

- The actual artifacts match the reviewed configuration and contain no unexpected secrets or agent/reference material.
- The owner's documented operating path works with the reviewed build; all support claims and phase-gate conclusions remain backed by evidence.

**Focused checks**

- Run one clean-source release build and the finite guide-validation path; record hashes, signatures, package contents and discrepancies.
- Keep release readiness pending for material findings and route fixes into bounded corrective tasks with targeted revalidation.

**Stop boundary / excluded work**

- Producing reviewable artifacts does not authorize publication, a push, purchases or communications to third parties.

Owned areas: `packaging/`, `docs/evidence/SC-034B/`, `docs/RELEASE_READINESS.md`, `docs/USER_GUIDE.md`.
