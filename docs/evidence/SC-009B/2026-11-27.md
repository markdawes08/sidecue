## Configuration and limits

The production adapter uses .NET `ClientWebSocket`, the fixed TLS Listen v1 endpoint, disabled redirects, explicit user-supplied model and model version, and diarizer `v1`. The defaults are two reconnects across an enumeration, a 250 ms retry delay, 10 s connection and credential resolution deadlines, 5 s send and drain deadlines, and a 3 s application keepalive. Response text is capped at 256 KiB and a frame at 64,000 bytes. The adapter holds at most one pending input read and one pending response for an active connection. Connection and send limits depend on cooperative abort of pending socket work. The configured default endpointing interval is 300 ms.

Clean drain requires final metadata and normal peer close. Caller cancellation stops enumeration, so the lifecycle owns cutoff reporting on that path. An unexpected failure during continued enumeration reports uncertainty and any unresolved tail. Provider results with ambiguous overlapping windows or unsupported timing still fail explicitly. The adapter can open before the first frame and can encounter the provider's first-audio deadline if startup is slow. These behavior choices follow the upstream protocol and were exercised through the transport seam where indicated. [Streaming API](https://developers.deepgram.com/reference/speech-to-text/listen-streaming) · [CloseStream](https://developers.deepgram.com/docs/close-stream) · [KeepAlive](https://developers.deepgram.com/docs/audio-keep-alive) · [Reconnect guidance](https://developers.deepgram.com/docs/recovering-from-connection-errors-and-timeouts-when-live-streaming-audio)

The credential resolver is injected. SC-010A owns wiring current-user DPAPI credentials, capture-status gap routing and disjoint speech epoch allocation across repeated source enumerations. SC-008B owns durable speaker provenance. SC-009C owns verification of the actual configured provider and model version. These local fakes do not establish production TLS, provider behavior or model quality. The parent task and phase gate remain open.
