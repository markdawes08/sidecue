## Procedure

From the repository root in Windows PowerShell. Each test invocation used a separate shell process. TRX files are under ignored `artifacts/test-results/`.

```powershell
powershell -NoProfile -File tools/build.ps1

# Native schema cases
. .\tools\common.ps1
$env:SIDECUE_SQLCIPHER_NATIVE_PATH = (Resolve-Path artifacts/sqlcipher-native/sqlcipher.dll).Path
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Infrastructure.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--filter', 'FullyQualifiedName~TranscriptSchemaTests',
    '--logger', 'trx;LogFileName=sc-008a-native.trx', '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))

# Default Infrastructure cases
. .\tools\common.ps1
if (Test-Path Env:SIDECUE_SQLCIPHER_NATIVE_PATH) { Remove-Item Env:SIDECUE_SQLCIPHER_NATIVE_PATH }
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Infrastructure.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--logger', 'trx;LogFileName=sc-008a-infrastructure.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))

# Architecture checks
. .\tools\common.ps1
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Architecture.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--logger', 'trx;LogFileName=sc-008a-architecture.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))
```

The first build exited 1 on xUnit3003. After forwarding caller source information from the opt-in test attribute, the locked Release build and all three test invocations exited 0. The final build reported zero warnings and errors. [xUnit analyzer rule](https://xunit.net/xunit.analyzers/rules/xUnit3003)
