## Procedure

Preconditions: the previously reviewed SQLCipher DLL and its manifest were present; all storage test directories were newly generated. From the repository root, PowerShell:

```text
powershell -NoProfile -File tools/probe-storage.ps1
powershell -NoProfile -File tools/test.ps1
```

Both commands exited 0. The probe builds the storage probe in Release with locked restore and starts fresh child processes under the current user. The test command performed a locked Release build and ran 153 deterministic tests, all passing, with no build warnings. The final probe was rerun after the loader's ancestor reparse-point guard was added; the full suite preceded that final guard, which was covered by the final build and focused probe. Test output and synthetic artifacts are local and ignored; no secret or private meeting data is recorded here.

The first probe attempt failed because an elevated token assigned the Administrators group as the default file owner. Creation was corrected to explicitly set the current user as owner for the key and database; the final probe passed. SQLite-created WAL/SHM files can use the token's default owner. Their allow ACLs are still checked for current-user-only access, and their owner must be the user or token default owner.

## Limitations and follow-up

- This is a local user-profile test, not a clean Windows VM, distinct-user DPAPI test, packaged build, installer/uninstaller test or portable-recovery claim. SC-004C retains clean-environment and distribution evidence.
- The loader requires all containing directories to be protected from untrusted modification and requires exclusive ownership of SQLitePCL provider initialization. It checks file identity and rejects reparse ancestors, but pathname-based loading cannot by itself rule out concurrent directory substitution. SC-004C tracks deployment verification before application wiring.
- Data-path ancestor checks reject reparse points, but the installer-directory comparison is lexical and does not resolve 8.3 aliases or substituted drives. Normal default `%LocalAppData%/SidecueData` selection was tested; no claim is made for hostile same-user path races.
- This implements an infrastructure adapter, not a transcript schema or application integration. DPAPI protects its key, not ordinary unencrypted SQLite. No phase gate is passed by this record.
