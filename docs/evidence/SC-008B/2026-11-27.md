## Procedure

Run from the repository root in Windows PowerShell. Test invocations ran in separate shell processes and wrote TRX files under ignored `artifacts/test-results/`.

```powershell
powershell -NoProfile -File tools/build.ps1

. .\tools\common.ps1
$env:SIDECUE_SQLCIPHER_NATIVE_PATH = (Resolve-Path artifacts/sqlcipher-native/sqlcipher.dll).Path
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Infrastructure.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--logger', 'trx;LogFileName=sc-008b-infrastructure.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))

. .\tools\common.ps1
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Replay.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--logger', 'trx;LogFileName=sc-008b-replay.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))
```

The initial build exited 1 because the session ID guard used an unavailable overload. The corrected locked Release build and both test invocations exited 0. After adding the rollback assertion, the locked build and Infrastructure rerun exited 0. The final build reported zero warnings and errors.
