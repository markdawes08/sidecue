## Procedure

From the repository root, run the display inspection. Use process inventory to identify the fresh app and check its exit independently of window inventory.

```powershell
powershell -NoProfile -File docs/evidence/SC-002C/inspect-displays.ps1
Get-Process Sidecue.Desktop -ErrorAction SilentlyContinue
Get-Process -Id 34984 -ErrorAction SilentlyContinue
```

Display inspection exited 0. The initial process check found no Sidecue instance. The process ID in the last command was the fresh test shell's ID. The command produced output while the process was present. After the final close, the process ID and name checks returned no process.

1. Confirm window inventory has no Sidecue shell or test picker. Start the ordinary-user test launcher `artifacts/sc-002c-local/LaunchSidecue.exe` through the Windows computer-use helper. The short-lived launcher had no window of its own. The helper found one fresh Sidecue shell, and process inventory confirmed the executable and process identity. [Launcher evidence](../SC-002C/2026-11-06-preflight.md)
2. Activate the shell and select **Choose screenshot target**. The button became disabled, the shell displayed **Choose a window or display.**, and the system picker appeared. Record that picker window's identity for comparison.
3. Activate the shell with the picker still present and send Alt+F4 to the shell. At 04:44:45, the same shell process and the same picker remained. Check the shell's system controls and activate its identified title-bar **Close** control. At 04:45:23, the same window identities and process still remained and the screenshot operation was pending.
4. Send Escape to the identified picker. It disappeared and Sidecue displayed **Screenshot canceled.** with the screenshot button enabled again. The first accessibility-only Close attempt on the restored shell reported unavailable click geometry. Refresh the test shell view and click its title-bar **Close** control directly. Both test windows were absent at 04:46:12. An independent process check at 04:46:17 confirmed the Sidecue process had exited.
