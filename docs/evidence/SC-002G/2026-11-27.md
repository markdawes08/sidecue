## Procedure

Run from the repository root in Windows PowerShell. The native and default test invocations used separate shell processes.

```powershell
powershell -NoProfile -File docs/evidence/SC-002C/inspect-displays.ps1
powershell -NoProfile -File tools/build.ps1

. .\tools\common.ps1
$env:SIDECUE_RUN_OVERLAY_FOCUS_PROBE = '1'
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Desktop.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--filter', 'FullyQualifiedName~OverlayForegroundTests',
    '--logger', 'trx;LogFileName=sc-002g-foreground-retry.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))

. .\tools\common.ps1
if (Test-Path Env:SIDECUE_RUN_OVERLAY_FOCUS_PROBE) { Remove-Item Env:SIDECUE_RUN_OVERLAY_FOCUS_PROBE }
Invoke-SidecueDotnet @('test', 'tests/Sidecue.Desktop.Tests', '-c', 'Release',
    '--no-build', '--no-restore', '--logger', 'trx;LogFileName=sc-002g-desktop.trx',
    '--results-directory', (Join-Path $repoRoot 'artifacts\test-results'))
```

The opt-in test launches a separate process with a read-only synthetic window. It waits until the window owns the actual Windows foreground, then shows the overlay and applies four updates through `OverlayHost.UpdateDisplay`. It checks the visible bound text, compares the foreground window after each update, and checks the target's deactivation signal after the updates settle. Both windows are closed at the end of the run. The fixture has a 24-second backstop. [Native foreground API](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getforegroundwindow)
