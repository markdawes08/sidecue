The initial integration build exposed an NAudio/Core `CaptureState` name collision, the NAudio 3 span-based `IWaveProvider` signature and xUnit cancellation-analyzer requirements. Those were corrected without weakening analyzer settings. The locked Release build then exited 0 with zero warnings/errors. The full suite exited 0 at 21:35: **95 passed, zero failed, zero skipped** (Core 27, Application 15, Replay 7, Architecture 7, Windows 28, Desktop 11).

Review then found two concrete issues: the native discontinuity flag was incorrectly labeled as an unavailable device, and End could race an in-flight callback and silently discard its packet. The gap now has a dedicated `CaptureDiscontinuity` reason, and End allows a packet already in flight to finish before closing the frame stream. A deterministic regression checks the callback/stop race. The two new gap reasons are additive to the current contract enum; downstream persisted/wire decoders must handle their values explicitly.
