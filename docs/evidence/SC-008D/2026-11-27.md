## Procedure

Run from the repository root in Windows PowerShell:

```powershell
powershell -NoProfile -File tools/build.ps1
powershell -NoProfile -File tools/probe-durability.ps1 -Transcript
powershell -NoProfile -File tools/probe-durability.ps1 -NoBuild
```

The probe seeded a committed final and gap with separate stream and timeline epochs. It exercised the production journal transaction using the reviewed native library. In the before case, a connection-local temporary trigger signaled readiness after the current revision pointer changed inside the amendment transaction. In the after case, the child signaled after receiving the applied commit receipt from the journal. The coordinator scanned the database, live WAL and protected key file, terminated its own child, and scanned the shared-memory file before reopening. The amendment fixture repeated its synthetic marker across enough data to exercise cache spill. [Temporary SQLite triggers](https://www.sqlite.org/lang_createtrigger.html#temp_triggers_on_non_temp_tables) · [SQLite cache spill](https://www.sqlite.org/pragma.html#pragma_cache_spill)

The first transcript invocation exited 1 while reading the shared-memory file during the child’s byte-range lock. The final probe scans that file after termination. The retried transcript command rebuilt the probe with zero warnings or errors and exited 0, as did the solution build and the previous probe mode.
